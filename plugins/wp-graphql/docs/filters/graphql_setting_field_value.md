# graphql_setting_field_value

```php
apply_filters( 'graphql_setting_field_value', $option, $setting_field, $group );
```

Filters the resolved value of a single settings field before it is returned in the Schema. This is the same seam applied by the grouped setting types, so a setting's value resolves consistently on both read surfaces.

## Parameters

- `$setting_field` (`array<string,mixed>`): The setting field config, including its `key` and `type`.
- `$group_name` (`string`): The name of the settings group the field belongs to.
